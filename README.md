# MIUI 主题扩展

一个 Xposed 模块，用于解锁 MIUI 主题壁纸中的付费内容，隐藏付费标识与商店广告。模块自带 Material Design 3 风格的配置界面，单一 APK。

## 功能

- **解锁付费主题与字体**——付费主题/字体/壁纸可视为免费直接下载应用
- **隐藏主题付费标识**——详情页价格/折扣控件归零显示
- **解锁付费大图标**——付费大图标主题可下载应用
- **解锁付费小组件**——智能助理/桌面/商店中的付费 MAML 小组件（含超级壁纸）可下载、可添加
- **隐藏小组件付费标识**——智能助理组件卡片不再显示付费角标
- **隐藏主题商店广告**——广告判定失效、广告卡片不占位
- **隐藏模块图标**——可隐藏桌面图标，仍可从 LSPosed 进入设置

各功能独立开关，默认全部关闭；开关更改后重新打开对应应用即可生效。

## 环境要求

- MIUI 12–14 的小米设备
- [LSPosed](https://github.com/LSPosed/LSPosed)（Xposed API 82 及以上）

## 使用方法

1. 安装 APK，在 LSPosed 中启用模块；
2. 勾选作用域：**Android 系统框架、MIUI 主题壁纸、MIUI 智能助理、MIUI 桌面** 四项（模块已声明推荐作用域，LSPosed 会默认勾选）；
3. 重启系统；
4. 打开模块开关需要的各项功能。

## 构建

```
./gradlew :app:assembleRelease
```

构建产物在 `app/build/outputs/apk/release/`。构建使用 JDK 25 工具链，经 foojay resolver 自动下载，无需本地预装。
